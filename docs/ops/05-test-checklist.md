# 05. 설치 후 점검표

학생들에게 알리기 **전에** 아래를 직접 해보세요. 10분이면 됩니다.

각 항목을 하고 `☐`를 `☑`로 바꿔가며 확인하시면 됩니다.

## A. 선생님 계정으로

| | 확인할 것 | 정상이면 |
|---|---|---|
| ☐ | 앱 주소 접속 | 파란 표지 화면 + "Google로 로그인" 버튼 |
| ☐ | 구글 로그인 | 곧바로 «오늘» 탭 (가입 화면이 뜨면 안 됨 — 이미 교사 명부에 있으므로) |
| ☐ | 위쪽에 이름과 «담임교사» 표시 | 이름이 나옴 |
| ☐ | 탭이 **5개** (오늘·달력·기도·자료·우리반) | 우리반 탭이 보임 |
| ☐ | «오늘» 탭에 오늘 날짜와 성경 본문 4개 | 가정 2개 + 개인 2개 |
| ☐ | 말씀읽음 체크 → 와닿은말씀 입력 → **저장하기** | "저장했습니다" 뜸 |
| ☐ | 스프레드시트를 열어 `RECORDS_2026-07` 탭 확인 | 방금 입력한 줄이 있음 |
| ☐ | «달력» 탭 | 오늘 날짜에 체크 표시, 연속 기록 1일 |
| ☐ | «기도» 탭에서 기도 하나 등록 | 목록에 펼쳐진 카드로 나타남 |
| ☐ | 그 기도의 **응답받았어요** 클릭 | 날짜 한 줄로 접힘 |
| ☐ | 접힌 줄 클릭 | 다시 펼쳐짐 |
| ☐ | «자료» 탭 → 소요리문답 열기 | 1번 문답부터 나옴 |
| ☐ | 자료에서 아무 단어 검색 | 결과 건수가 표시됨 |
| ☐ | «우리반» 탭 | 본인이 학생/학부모 목록에 없음 (교사는 명부에서 제외) |

## B. 학생 입장 확인 (다른 계정 필요)

가족 계정이나 부계정으로 해보시면 좋습니다.

| | 확인할 것 | 정상이면 |
|---|---|---|
| ☐ | 다른 구글 계정으로 로그인 | **가입 화면**이 뜸 |
| ☐ | 코드를 **일부러 틀리게** 입력 | "등록 코드가 올바르지 않습니다" |
| ☐ | 이름을 비우고 등록 | "입력한 내용을 다시 확인해 주세요" |
| ☐ | «학생이에요» 선택 + 이름 + 올바른 코드 → 등록 | 바로 «오늘» 탭 진입 |
| ☐ | 탭이 **4개** (우리반 없음) ★ | **우리반 탭이 안 보여야 함** |
| ☐ | 스프레드시트 `MEMBERS_학생` 탭 | 방금 가입한 사람이 추가됨 |
| ☐ | 기도를 하나 등록 | 등록됨 |
| ☐ | 선생님 계정으로 돌아가 «우리반» → «기도제목» | 그 학생의 기도가 보임 |
| ☐ | 그 기도에 응답 체크 버튼이 있는지 ★ | **없어야 함** (본인만 가능) |

## C. ★ 보안 점검 (가장 중요 — 꼭 해보세요)

| | 확인할 것 | 정상이면 |
|---|---|---|
| ☐ | **같은 휴대폰**에서 학생 계정으로 로그인 → 기도 탭 보기 → **로그아웃** → 선생님 계정으로 로그인 | 앞사람의 기도제목이 **보이지 않아야 함** |
| ☐ | 학생 계정으로 로그인한 상태에서 «우리반» 탭이 없음 | 없음 |
| ☐ | 스프레드시트가 **아무에게도 공유되어 있지 않은지** — 시트 오른쪽 위 «공유» 클릭해서 확인 | 선생님만 있음 |

> 마지막 항목이 이 앱 보안의 핵심입니다. "링크가 있는 모든 사용자"로 되어 있으면
> **즉시 «제한됨»으로 바꾸세요.**

## D. 휴대폰에서

| | 확인할 것 | 정상이면 |
|---|---|---|
| ☐ | 휴대폰 브라우저로 접속 | 화면이 세로로 꽉 참 |
| ☐ | 홈 화면에 추가 | 아이콘이 생김 |
| ☐ | 아이콘으로 실행 | 주소창 없이 앱처럼 열림 |
| ☐ | **앱을 켠 상태에서** «자료» → 소요리문답을 연 뒤 → **비행기 모드로 전환** → 목록으로 나갔다가 다시 소요리문답 열기 | 본문이 그대로 보임 |
| ☐ | 그 상태(비행기 모드)에서 «오늘» 탭 저장 시도 | **"서버에 연결하지 못했습니다…" 안내가 뜨고 입력이 지워지지 않음** |
| ☐ | 비행기 모드 해제 → 저장 다시 시도 | 정상 저장됨 |
| ☐ | **앱을 완전히 끄고 → 비행기 모드 → 앱 실행 → 로그인** | «기록을 불러오지 못했습니다…»와 **«다시 시도» 버튼**이 뜸 (빈 화면·«연속 0일»이 뜨면 안 됨) |
| ☐ | 비행기 모드 해제 → «다시 시도» 클릭 | 정상 진입 |

> ⚠️ **앱을 완전히 끈 뒤 비행기 모드로 다시 켜면 로그인 화면에서 멈춥니다.** 정상입니다 —
> 로그인 정보를 휴대폰에 저장하지 않기 때문이며, 그것이 이 앱이 남의 기록을 막는 방식입니다.
> 오프라인에서 보장되는 것은 "쓰는 중에 끊겨도 계속 볼 수 있다"까지입니다.
