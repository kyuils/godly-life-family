# 00. 시작하기 — 전체 순서

이 앱을 처음 설치하는 분을 위한 안내입니다. **개발 지식이 없어도 따라 할 수 있게** 썼습니다.

## 먼저 알아두실 것

이 앱은 세 조각으로 되어 있습니다.

| 조각 | 무엇인가 | 어디에 있나 |
|---|---|---|
| **화면** | 학생·학부모가 보는 앱 | GitHub Pages (인터넷 주소) |
| **서버** | 저장·조회를 처리하는 프로그램 | Google Apps Script (선생님 계정) |
| **저장소** | 실제 데이터가 쌓이는 곳 | Google 스프레드시트 (선생님 드라이브) |

**중요**: 스프레드시트는 **선생님 것이고, 아무에게도 공유하지 않습니다.**
학생·학부모는 앱을 통해서만, 그것도 **자기 것만** 볼 수 있습니다. 이것이 이 앱의 보안 구조입니다.

## 미리 준비할 것

- 구글 계정 (선생님 본인 것. 이 계정이 관리자가 됩니다)
- GitHub 계정
- PC (휴대폰으로는 설치가 어렵습니다)

## 설치 중 적어둘 값 3개

진행하면서 아래 3개를 메모장에 적어 두세요. 나중에 쓰입니다.

```
① 스프레드시트 ID   : (02번 문서에서)
② OAuth 클라이언트 ID : (01번 문서에서)
③ Apps Script 웹앱 주소 : (03번 문서에서)
```
