# 02. 스프레드시트 만들기

데이터가 실제로 쌓일 곳입니다.

## 1. 시트 만들기

1. [sheets.new](https://sheets.new) 접속 (선생님 계정으로 로그인된 상태에서)
2. 왼쪽 위 **제목 없는 스프레드시트**를 클릭해서 이름을 `경건생활 DB`로 바꿉니다.

**탭(시트)은 직접 만들지 마세요.** 다음 단계에서 프로그램이 자동으로 만듭니다.

## 2. 시트 ID 복사 ★

주소창을 보면 이렇게 되어 있습니다:

```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890/edit#gid=0
                                       └──────────── 이 부분이 시트 ID ────────────┘
```

`/d/` 와 `/edit` 사이의 긴 문자열을 복사해서 메모장에 적어 둡니다.

## 적어둘 값

```
① 스프레드시트 ID : 1AbCdEfGhIjKlMnOpQrStUvWxYz1234567890
```

## 3. ★ 절대 하지 말아야 할 것

> ### 🚫 이 스프레드시트를 **누구에게도 공유하지 마세요.**
>
> 학생·학부모에게 공유하면 **모든 사람의 기도제목과 기록이 그대로 보입니다.**
> 앱이 보안을 지키는 방식이 바로 "시트는 선생님만 열 수 있다"는 것입니다.
>
> 학생이 "안 보여요"라고 하면 시트를 공유하는 게 아니라, 앱에 가입시켜야 합니다.
> (→ [06-operations.md](06-operations.md))

## 4. 나중에 시트를 열어볼 때 지켜야 할 규칙

설치가 끝나면 아래 탭들이 생깁니다.

| 탭 이름 | 내용 | 손으로 고쳐도 되나 |
|---|---|---|
| `MEMBERS_학생` | 학생 명부 | ✅ 됩니다 |
| `MEMBERS_학부모` | 학부모 명부 | ✅ 됩니다 |
| `MEMBERS_교사` | 교사 명부 | ✅ 됩니다 |
| `RECORDS_2026-07` 등 | 날짜별 기록 (매달 자동 생성) | ❌ **보기만** |
| `PRAYERS` | 기도 요청 | ❌ **보기만** |

> ### ⚠️ `RECORDS_*` 와 `PRAYERS` 탭에서 하면 안 되는 것
>
> - **정렬** (데이터 → 정렬, 열 머리글 정렬 버튼)
> - **행 삽입 / 행 삭제**
> - **열 이동 / 열 삽입**
>
> **왜?** 앱은 "몇 번째 줄"을 기억해서 저장합니다. 선생님이 정렬하는 그 순간에 학생이 저장하면
> **A 학생의 기록이 B 학생 줄에 덮어써질 수 있습니다.** 되돌릴 수 없습니다.
>
> **정렬해서 보고 싶으면**: 데이터 → **필터 보기 만들기** 를 쓰세요.
> 필터 보기는 선생님 화면에서만 정렬되고 실제 데이터 순서는 그대로입니다.

설치 마지막에 이 탭들에 자동으로 **보호**를 걸어 둡니다.
다만 그 보호는 «다른 사람»을 막는 것이라 **시트 주인인 선생님은 여전히 정렬·삭제가 되고
경고창도 뜨지 않습니다.** 이 시트에 접근할 수 있는 사람은 선생님 한 분뿐이므로,
실질적으로 **선생님이 스스로 지키셔야 하는 규칙**입니다.
앱에 2차 안전장치가 있어 대부분 막아 주지만(그럴 때 학생 화면에 "잠시 후 다시 시도"가 뜹니다),
애초에 건드리지 않는 것이 최선입니다.

## 이럴 때는

**시트 ID를 잘못 적었어요**
→ 03번 문서에서 다시 붙여넣고 `setupAll`을 다시 실행하면 됩니다. 여러 번 해도 안전합니다.
