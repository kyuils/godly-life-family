# 01. 구글 로그인 키 발급

앱에서 "구글 계정으로 로그인"이 되게 하려면, 구글에서 **키(클라이언트 ID)** 를 하나 받아야 합니다.
비밀번호가 아니라 "이 앱이 구글 로그인을 써도 된다"는 허가증입니다.

> 이 키는 앱 화면에 그대로 노출되는 값이라 **비밀이 아닙니다.** 숨기지 않아도 됩니다.

## 1. 프로젝트 만들기

1. [console.cloud.google.com](https://console.cloud.google.com) 접속 → 선생님 구글 계정으로 로그인
2. 화면 맨 위 왼쪽의 **프로젝트 선택** 드롭다운 클릭 → **새 프로젝트**
3. 이름: `경건생활앱` → **만들기**
4. 만들어지면 다시 드롭다운에서 그 프로젝트를 선택 (이후 작업이 이 프로젝트 안에서 이뤄집니다)

## 2. 동의 화면 설정

로그인할 때 사용자에게 보여줄 안내 화면입니다.

1. 왼쪽 메뉴 → **API 및 서비스** → **OAuth 동의 화면**
2. User Type: **외부** 선택 → **만들기**
3. 입력:
   - 앱 이름: `경건생활`
   - 사용자 지원 이메일: 선생님 이메일
   - 개발자 연락처 정보: 선생님 이메일
4. **저장 후 계속** → 범위 화면에서도 그냥 **저장 후 계속**
5. 테스트 사용자 화면: **아무것도 추가하지 않아도 됩니다** → 저장 후 계속

> **"게시 상태"가 «테스트»여도 괜찮습니다.** 이 앱은 구글에서 개인정보를 가져오지 않고
> 로그인 확인만 하므로, 테스트 상태에서도 정상 동작합니다.
> 만약 로그인이 막히면 **대상** 화면에서 **앱 게시** 버튼을 눌러 «프로덕션»으로 바꾸세요.

## 3. 클라이언트 ID 발급 ★

1. 왼쪽 메뉴 → **API 및 서비스** → **사용자 인증 정보**
2. 위쪽 **+ 사용자 인증 정보 만들기** → **OAuth 클라이언트 ID**
3. 애플리케이션 유형: **웹 애플리케이션**
4. 이름: `경건생활 웹`
5. **승인된 JavaScript 원본**에 아래 두 개를 **+ URI 추가**로 넣습니다:

   ```
   https://kyuils.github.io
   http://localhost:8788
   ```

   > 위쪽은 실제 앱 주소, 아래쪽은 PC에서 미리보기할 때 쓰는 주소입니다.
   > GitHub 아이디가 `kyuils`가 아니면 그 부분을 본인 아이디로 바꾸세요.

   **"승인된 리디렉션 URI"는 비워 둡니다.** 이 앱은 쓰지 않습니다.

6. **만들기** → 팝업에 나오는 **클라이언트 ID**를 복사해서 메모장에 적어 둡니다.

   생김새: `123456789012-abcdefghijk....apps.googleusercontent.com`

   > **클라이언트 보안 비밀번호(client secret)는 쓰지 않습니다.** 무시하세요.

## 적어둘 값

```
② OAuth 클라이언트 ID : 123456789012-....apps.googleusercontent.com
```

## 이럴 때는

**"승인된 JavaScript 원본" 주소를 모르겠어요**
→ 04번 문서에서 GitHub Pages 주소가 확정됩니다. 일단 `http://localhost:8788`만 넣고 만든 뒤,
   04번을 끝내고 다시 이 화면에 돌아와 주소를 추가해도 됩니다.

**나중에 로그인 버튼을 눌렀는데 "400 오류: redirect_uri_mismatch"가 나요**
→ 5번의 **승인된 JavaScript 원본**에 앱 주소가 빠졌거나 오타가 있습니다.
   주소 끝에 `/`를 붙이면 안 됩니다. `https://kyuils.github.io` (O), `https://kyuils.github.io/` (X)

**변경했는데 그대로예요**
→ 구글 설정은 반영에 몇 분 걸립니다. 5분 기다린 뒤 브라우저 새로고침(Ctrl+F5)하세요.
