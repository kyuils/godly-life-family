# 07. 이번 업데이트 올리기 (v1.2 — 가입 3분류)

> **처음 설치가 아닙니다.** 이미 돌아가고 있는 앱에 «혜림교회 성도» 분류를 더하는 작업입니다.
> 화면(GitHub)은 **이미 올라가 있습니다.** 여기서 하실 일은 **서버(Apps Script) 하나뿐**입니다.
> 걸리는 시간 약 10분.

## 왜 서버를 먼저 올려야 하나

지금은 화면만 새 버전이라, 새로 가입하는 분이 «혜림교회 성도»를 고르면
서버가 모르는 값이라 **«입력한 내용을 다시 확인해 주세요»** 라는 엉뚱한 안내가 뜹니다.
서버를 올리면 바로 맞춰집니다. 데이터가 상하지는 않습니다.

---

## 1. 되돌릴 수단 만들기 (건너뛰지 마세요)

1. 스프레드시트를 엽니다
2. **파일 → 사본 만들기** → 이름 뒤에 `백업 2026-07-31` 정도로 적고 저장

무슨 일이 생겨도 이 사본으로 돌아올 수 있습니다.

## 2. `MEMBERS_학생` 시트의 **G열** 확인 ★

새 버전은 학생 명부의 **G열에 «학교»** 를 씁니다. 그래서 두 가지를 눈으로 봅니다.

| 볼 것 | 정상 | 정상이 아니면 |
|---|---|---|
| G열이 **있는지** (A부터 세어 일곱 번째 열) | 있음 | 열이 6개까지만 있으면, 아무 열이나 오른쪽 클릭 → «오른쪽에 1열 삽입» |
| G열이 **비어 있는지** (1행 포함 전부) | 비어 있음 | 내용이 있으면 다른 곳으로 옮긴 뒤 진행 |

> 비어 있지 않은 채로 진행하면 이름표(«학교»)와 실제 내용이 어긋납니다.
> A~F열(email·이름·학년반·active·가입시각·가입경로)은 **건드리지 않습니다.**

## 3. 코드 파일 5개 바꿔 넣기

스프레드시트 → **확장 프로그램 → Apps Script** 로 편집기를 엽니다.

저장소의 `gas/` 폴더에 있는 아래 5개를, 편집기의 같은 이름 파일에 **전체 선택 후 붙여넣기** 합니다.

- `Sheet.gs`
- `Auth.gs`
- `Actions.gs`
- `Setup.gs`
- `Code.gs`

각 파일마다 `Ctrl+A` → `Ctrl+V` → `Ctrl+S`.

## 4. `Setup.gs`에서 **딱 한 줄만** 채우기 ★★

`Setup.gs` 위쪽에 `PASTE_...` 라고 적힌 줄이 넷 있습니다.

| 줄 | 어떻게 |
|---|---|
| `SETUP_SHEET_ID` | 스프레드시트 ID를 **채웁니다** |
| `SETUP_OAUTH_CLIENT_ID` | **그대로 둡니다** (`PASTE_...`) |
| `SETUP_ADMIN_EMAIL` | **그대로 둡니다** |
| `SETUP_REGISTER_CODE` | **그대로 둡니다** |

> **왜 하나만?** `PASTE_`로 두면 기존에 설정해 둔 값이 **보존**됩니다.
> 반대로 구글 로그인 키를 다시 채우다 한 글자라도 틀리면 **모든 사용자가 로그인할 수 없게 됩니다.**
> 채울 필요가 없습니다.

스프레드시트 ID는 시트 주소에서 `/d/` 와 `/edit` 사이의 긴 문자열입니다.

```
https://docs.google.com/spreadsheets/d/여기가ID입니다/edit
```

`Ctrl+S`로 저장합니다.

## 5. 초기 설정 실행

1. 편집기 위쪽 함수 목록에서 **`setupAll`** 선택
2. **▶ 실행**
3. 아래 로그에 **`SETUP COMPLETE`** 가 보이면 성공

> 기존 데이터는 지워지지 않습니다. 이 작업이 하는 일은 «`MEMBERS_성도` 시트 만들기»와
> «`MEMBERS_학생`의 G1에 «학교»라고 적기» 두 가지뿐입니다.

## 6. 시트에서 눈으로 확인

| 볼 것 | 정상 |
|---|---|
| 탭 목록 | **`MEMBERS_성도`** 가 새로 생겼다 |
| `MEMBERS_학생`의 **G1 칸** | 정확히 **`학교`** |

> G1은 **손으로 타이핑하지 마세요.** `setupAll`이 써 줍니다.
> 앞뒤에 공백이 들어가면 학생 가입이 «서버 설정이 완료되지 않았습니다»로 실패합니다.

## 7. 새 버전으로 배포 ★

**붙여넣기만 해서는 실제 앱에 반영되지 않습니다.** 배포된 버전은 고정되어 있습니다.

1. 편집기 오른쪽 위 **배포 → 배포 관리**
2. 기존 배포 오른쪽의 **연필(수정)** 아이콘
3. 버전 칸에서 **«새 버전»** 선택
4. **배포**

> ❌ **«새 배포»를 만들면 안 됩니다.** 주소가 바뀌어서 앱이 옛 서버를 계속 부릅니다.
> 반드시 **배포 관리 → 수정 → 새 버전** 입니다.

## 8. 서버가 새 버전인지 확인

웹앱 주소를 브라우저 주소창에 그대로 붙여 넣고 엽니다. 이런 글자가 보입니다.

```
{"ok":true,"build":"v1.2.0", ...}
```

**`build`가 `v1.2.0`** 이면 끝났습니다. 이전 값(`v1.1.x`)이 그대로면 7번이 안 된 것입니다.
