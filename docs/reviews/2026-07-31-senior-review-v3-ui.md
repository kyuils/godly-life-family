## 1. 계획이 틀린 것

| r1의 주장 | 실제 (1차 출처) |
|---|---|
| 좌우 여백 24px | `.appbar-inner{padding:0 var(--space-16)}` = **32px** |
| 간격 12px | `gap:var(--space-8)` × 2 = **16px** |
| 로그아웃 62px | 패딩 24 + 테두리 2 + 글자 ≥52 = **≥78px** |
| 「로그아웃을 sm으로 줄인다」 | `index.html:120`이 **이미** `btn sm ghost` — **no-op** |
| 「`.topnav`가 overflow-x라 밀린다」 | `button{flex:1 1 0;min-width:0}` — **밀리지 않고 줄어든다** |
| 탭 폭 43px | **36px(390px 기기) / 30px(360px 기기)** |

탭 안쪽 여백을 빼면 글자가 쓸 수 있는 폭은 **22~28px**. 「우리반」이 10px 폰트로도
안 들어간다. 계약 §7.1과 `check-web.mjs`가 「6탭이 되면 작아진다」를 근거로 홈을 탭에서
뺐는데, 이 변경은 5탭을 그보다 나쁘게 만들어 근거를 무너뜨린다.

## 2. [중대] 지적과 조치

| 지적 | 조치 |
|---|---|
| **`localStorage`가 `check-web.mjs:120`을 반드시 실패시킨다.** 그 검사는 보안 불변식 7의 유일한 자동 가드이고, 예외를 뚫으면 앞으로 추가되는 모든 파일에 구멍이 남는다 | 설치 안내를 **로그인·가입 화면**으로 옮겨 «닫음» 상태 자체를 없앴다. 요청 원문(「가입고 로그인시」)에도 이쪽이 정확하다 |
| 요청 2를 홈에 두면 요청 3이 되찾은 56px을 그 자리에서 도로 쓴다 | 위와 같은 조치로 해소 |
| `beforeinstallprompt`가 모듈 평가보다 **먼저** 발화할 수 있다(module = defer). 놓치면 안내가 «떴다 안 떴다» 한다 | `index.html` `<head>`에 인라인으로 스태시 → `window.__bip` |
| 점 없는 `matchMedia(`는 «정의되지 않은 호출» 검사에 걸린다 | `window.matchMedia(...)` |
| `package.json`은 명시적 체인이라 `test-install.mjs`가 자동으로 안 돈다 | 체인에 추가. 안 하면 «테스트를 쓰고도 한 번도 실행 안 됨» |
| `.nav-sheet`에 grid 한 줄만 주면 **좌우 교대 배치**가 된다(직계 자식이 평면) | `view-library.js`에서 `.nav-col` 래퍼 2개로 재구조화 |
| `.sheet-body`는 definite height가 아니라 `overflow-y:auto`만으로 단별 스크롤이 안 된다 | `.nav-sheet{max-height:66dvh}` + 각 단 `min-height:0` |
| `.section-head`는 달력·우리반·기도 화면이 **함께 쓴다** | `.lib-head` 신설 |
| 2단의 진짜 비용은 왼쪽이 아니라 **오른쪽 목차**(미리보기 22자 → 10자) | `nav-toc-no` 34px + sub 2줄 허용 |
| 설치된 상태에서 **로그인이 되는지 아무도 확인하지 않았다.** 세션이 메모리 전용이라 카톡 사고와 같은 클래스 | 실기기 확인을 사용자 확인 항목으로 넘김 |

## 3. 요청 3 — 대안 채택

계획의 「탭을 제목줄 안으로」를 **드롭**하고 아래로 대체했다.

```
.appbar : position:sticky → static
.topnav : top:calc(safe-area + --appbar-h) → top:env(safe-area-inset-top)
```

- 상시 점유 120px → 64px (**56px 회복** — 계획이 노린 60px과 사실상 같다)
- **탭 크기를 하나도 잃지 않는다**
- 앱바 배경(코랄)과 탭 배경(흰색)이 섞이는 문제, 활성 탭 표시가 사라지는 문제가
  아예 발생하지 않는다
- 되돌리기는 CSS 두 줄

사용자에게는 수단이 바뀐 이유와 함께, 원하면 요청대로 바꿀 수 있음을 알렸다.

## 6. 자동으로 확인할 수 없는 것 (사람이 봐야 한다)

1. **설치 안내** — 로컬에서는 서비스워커를 등록하지 않아 `beforeinstallprompt`가
   아예 발화하지 않는다. 실기기에서만 확인된다.
2. **설치 후 로그인** — 세션이 메모리 전용이라 iOS standalone에서 실패할 수 있다.
   실패하면 iOS 안내를 보류한다.
3. **메뉴 크기 체감** — 요청 3의 대안이 사용자에게 충분한지.
