# 경건생활 — 청소년부 & 학부모

혜림교회 청소년부 학생과 학부모가 매일의 **날주(맥체인 성경읽기)** 를 기록하고,
담임교사에게 기도를 요청하며, 개혁주의 신앙고백 자료를 찾아보는 휴대폰용 웹앱입니다.

> 사용자는 **자기 기록만** 볼 수 있고, 담임교사만 반 전체를 조회합니다.
> 데이터는 담임교사 계정의 Google 스프레드시트에 저장되며 **아무에게도 공유되지 않습니다.**

## 처음 설치하시나요?

👉 **[docs/ops/00-quickstart.md](docs/ops/00-quickstart.md)** 부터 순서대로 따라가세요.
개발 지식 없이도 따라 할 수 있게 클릭 순서까지 적어두었습니다. 약 40~60분 걸립니다.

## 기능

| 탭 | 내용 |
|---|---|
| **오늘** | 맥체인 본문 4개 · 말씀읽음 체크 · 와닿은 말씀 · 결단 · 중보기도 체크 |
| **달력** | 한 달 달력으로 내 기록 한눈에. 날짜를 누르면 그날 상세 |
| **기도** | 담임교사에게 기도 요청. 월별 묶음. 미응답은 펼쳐두고, 응답된 건 날짜만 접어서 표시 |
| **자료** | 신앙고백서 · 소요리 · 대요리 · 예배모범 · 신조 · 하이델베르크 (검색 가능, 오프라인 열람) |
| **우리반** | (교사만) 학생·학부모 현황과 기도제목 열람 |

## 구조

```
[휴대폰]  ──구글 로그인──▶  [화면: GitHub Pages]
                                    │  로그인 토큰
                                    ▼
                          [서버: Apps Script]  ← 담임교사 계정으로 실행
                                    │  서버만 접근 가능
                                    ▼
                          [저장소: Google 스프레드시트]  ← 비공유
```

| 폴더 | 내용 |
|---|---|
| `web/` | 화면 (정적 PWA) |
| `gas/` | 서버 (Google Apps Script) |
| `web/data/` | 참고자료 JSON (읽기 전용, 오프라인용) |
| `scripts/` | 검증 하네스 + 자료 수집 스크립트 |
| `docs/ops/` | **설치·운영 문서 (비개발자용)** |
| `docs/specs/` | 데이터·API 계약 (개발 기준 문서) |
| `docs/reviews/` | 시니어 검토 기록 |

## 개발

```bash
npm test
```

| 검사 | 항목 |
|---|---|
| `check-web.mjs` | 프론트 정적 검사 (캐시 격리·배포 설정·XSS·모듈 참조) |
| `test-gas-actions.mjs` | 백엔드 + **보안 회귀 테스트 6종** |
| `test-stats.mjs` | 지표 계산 (연속기록·달성률·달력) |
| `test-library-data.mjs` | 참고자료 JSON 무결성 |
| `test-mccheyne.mjs` | 맥체인 성경읽기표 |

로컬 미리보기 (실제 서버 코드가 그대로 돌아갑니다):

```bash
node scripts/mock-server.mjs 8788
```

> `web/js/config.js`를 임시로 `GAS_URL: '/api'`, `MOCK: 'student1@example.com'` 으로 바꾼 뒤
> http://localhost:8788 접속. 교사 화면은 `MOCK: 'teacher@example.com'`.
> **커밋 전 반드시 원래대로 되돌리세요** — `npm test`가 검사합니다.

참고자료 다시 수집:

```bash
node scripts/fetch-library.mjs
```

## 보안 원칙

1. 서버는 **검증된 로그인 토큰의 이메일만** 신뢰합니다. 클라이언트가 보낸 이메일·권한은 무시합니다.
2. **교사 권한은 시트를 사람이 직접 편집해야만** 부여됩니다. 가입 화면으로는 불가능합니다.
3. 기도제목은 **본인과 교사만** 볼 수 있습니다. 응답 체크는 **본인만** 가능합니다.
4. 프론트 캐시는 계정별로 분리되고 메모리에만 있으며, 계정 전환 시 즉시 파기됩니다.
   (가정에서 휴대폰을 공유하는 상황을 전제로 설계했습니다)
5. 배포는 **"나(소유자)로 실행 / 모든 사용자 접근"** 이며, 스프레드시트는 공유하지 않습니다.
